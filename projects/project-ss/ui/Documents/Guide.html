UI 미리보기로 돌아가기포트폴리오

Project SS UI 미리보기

게임에서 제작한 UI를 브라우저에서 체험할 수 있도록 옮겼습니다. 메뉴를 직접 눌러 화면의 구성과 이동 흐름을 확인할 수 있습니다.

화면 살펴보기

왼쪽에서 큰 분류를 고르고, 위쪽 탭에서 세부 화면을 선택하세요. 화면 아래의 체험 버튼으로 HP와 장착 상태 등을 바꿔볼 수 있습니다. 오른쪽 위의 ‘화면 확대’를 누르면 게임 화면만 크게 볼 수 있습니다.

조작 방법

  • 마우스로 메뉴와 버튼을 선택할 수 있습니다.
  • 키보드: 방향키 이동, Enter 결정, Backspace 취소, Q/E 탭 전환
  • 게임패드: 방향키·스틱 이동, A 결정, B 취소, LB/RB 탭 전환

체험 범위

이 미리보기는 UI와 메뉴 흐름을 확인하기 위한 웹 체험입니다. 저장은 현재 브라우저에만 적용됩니다. 실제 전투와 게임 플레이는 포트폴리오에 연결한 데모 빌드와 플레이 영상에서 확인할 수 있습니다.
